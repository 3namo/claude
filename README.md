# 津田沼駅周辺マップ

OpenStreetMapと国土地理院のオープンデータを活用した、津田沼駅周辺の地域情報マップです。

## 特徴

### 🗺️ 複数の地図レイヤー
- **OpenStreetMap**: 詳細な街路情報
- **国土地理院（標準地図）**: 日本の公式地図データ
- **国土地理院（航空写真）**: リアルな地形を確認

### 📍 豊富な施設情報
17の主要施設を6つのカテゴリに分類：
- 🚉 駅・交通（3施設）
- 🛍️ ショッピング（4施設）
- 🎓 教育機関（2施設）
- 🏥 医療機関（2施設）
- 🏛️ 公共施設（3施設）
- 🌳 公園（3施設）

### 🎨 ユーザーフレンドリーな機能
- **カテゴリフィルター**: 見たい施設だけを表示
- **カラフルなマーカー**: カテゴリごとに色分け
- **詳細なポップアップ**: 各施設の説明を表示
- **レスポンシブデザイン**: スマートフォンでも快適に閲覧

## 使用技術

### フロントエンド
- **HTML5/CSS3**: モダンなレイアウトとデザイン
- **JavaScript (Vanilla)**: 軽量で高速な動作
- **Leaflet.js 1.9.4**: 高機能な地図ライブラリ

### データソース
- **OpenStreetMap**: オープンソースの地図データ
- **国土地理院**: 日本の公式地図タイル
- **公共施設オープンデータ**: 地域の施設情報

## セットアップ

### 必要な環境
- モダンなウェブブラウザ（Chrome, Firefox, Safari, Edge）
- インターネット接続（地図タイルの読み込みに必要）

### インストール

1. リポジトリをクローン
```bash
git clone <repository-url>
cd claude
```

2. ブラウザで開く
```bash
# シンプルなHTTPサーバーを起動（Python 3の場合）
python -m http.server 8000

# または Node.js の場合
npx serve
```

3. ブラウザで `http://localhost:8000` にアクセス

### ファイル構成
```
claude/
├── index.html      # メインHTML
├── styles.css      # スタイルシート
├── app.js          # メインアプリケーションロジック
├── data.js         # 施設データ
└── README.md       # このファイル
```

## 使い方

### 基本操作
1. **地図の移動**: ドラッグ or スワイプ
2. **ズーム**: マウスホイール or ピンチイン/アウト
3. **施設情報を見る**: マーカーをクリック

### レイヤー切り替え
サイドバーの「地図レイヤー」セクションで、表示する地図を選択できます。

### 施設フィルター
サイドバーの「施設カテゴリ」セクションで、表示する施設の種類を選択できます。

## カスタマイズ

### 施設を追加する

`data.js` の `facilities` 配列に新しい施設を追加：

```javascript
{
    id: 18,
    name: "新しい施設",
    category: "shopping",  // station, shopping, education, medical, public, park
    lat: 35.6916,
    lng: 140.0211,
    description: "施設の説明",
    icon: "🏪"
}
```

### カテゴリを追加する

1. `data.js` の `categoryConfig` に新しいカテゴリを追加
2. `index.html` のフィルターチェックボックスに追加

### スタイルをカスタマイズ

`styles.css` を編集して、色やレイアウトを変更できます。

## API キーについて

このプロジェクトは**APIキー不要**で動作します。使用している全てのサービスは公開されているオープンデータです。

### 将来的に追加可能な機能
以下の機能を追加する場合、APIキーの取得が必要になります：

- **e-Stat API**: 詳細な統計データ
  - 取得先: https://www.e-stat.go.jp/api/
  - 無料、メール登録が必要

- **天気情報**: OpenWeatherMap など
  - 取得先: https://openweathermap.org/api
  - 無料プランあり

## トラブルシューティング

### 地図が表示されない
- インターネット接続を確認してください
- ブラウザのコンソールでエラーを確認してください
- ブラウザのキャッシュをクリアしてみてください

### マーカーが表示されない
- JavaScriptが有効になっているか確認してください
- `data.js` が正しく読み込まれているか確認してください
