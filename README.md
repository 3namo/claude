# 津田沼駅周辺マップ

OpenStreetMapと国土地理院のオープンデータを活用した、津田沼駅周辺の地域情報マップです。

## 特徴

### 🗺️ 複数の地図レイヤー
- **OpenStreetMap**: 詳細な街路情報
- **国土地理院（標準地図）**: 日本の公式地図データ
- **国土地理院（航空写真）**: リアルな地形を確認

### 📍 豊富な施設情報
21の主要施設を7つのカテゴリに分類：
- 🚉 駅・交通（3施設）
- 🛍️ ショッピング（4施設）
- 🎓 教育機関（2施設）
- 🏥 医療機関（2施設）
- 🏛️ 公共施設（3施設）
- 🌳 公園（3施設）
- 🛡️ 防災施設（4施設）

### 🎨 ユーザーフレンドリーな機能
- **カテゴリフィルター**: 見たい施設だけを表示
- **カラフルなマーカー**: カテゴリごとに色分け
- **詳細なポップアップ**: 住所、営業時間、電話番号、ウェブサイト
- **ルート案内**: 津田沼駅・現在地からの距離と徒歩時間
- **現在地表示**: GPS位置情報の取得と表示
- **レスポンシブデザイン**: スマートフォンでも快適に閲覧

### 🌤️ リアルタイム情報
- **天気情報**: 津田沼駅周辺の現在の天気、気温、湿度、風速（10分ごとに自動更新）
- **統計情報**: 習志野市の人口統計、年齢別構成、主要施設数

## 使用技術

### フロントエンド
- **HTML5/CSS3**: モダンなレイアウトとデザイン
- **JavaScript (Vanilla)**: 軽量で高速な動作
- **Leaflet.js 1.9.4**: 高機能な地図ライブラリ

### データソース
- **OpenStreetMap**: オープンソースの地図データ
- **国土地理院**: 日本の公式地図タイル
- **公共施設オープンデータ**: 地域の施設情報
- **OpenWeatherMap API**: リアルタイム天気情報
- **e-Stat API**: 政府統計データ（習志野市）

## セットアップ

### 必要な環境
- モダンなウェブブラウザ（Chrome, Firefox, Safari, Edge）
- インターネット接続（地図タイルの読み込みに必要）

### インストール

1. リポジトリをクローン
```bash
git clone <repository-url>
cd claude
```

2. ブラウザで開く
```bash
# シンプルなHTTPサーバーを起動（Python 3の場合）
python -m http.server 8000

# または Node.js の場合
npx serve
```

3. ブラウザで `http://localhost:8000` にアクセス

### ファイル構成
```
claude/
├── index.html      # メインHTML
├── styles.css      # スタイルシート
├── app.js          # メインアプリケーションロジック
├── data.js         # 施設データ
├── config.js       # API設定
├── weather.js      # 天気情報取得
├── statistics.js   # 統計情報処理
├── README.md       # このファイル
└── SECURITY.md     # セキュリティ設定ガイド
```

## 使い方

### 基本操作
1. **地図の移動**: ドラッグ or スワイプ
2. **ズーム**: マウスホイール or ピンチイン/アウト
3. **施設情報を見る**: マーカーをクリック

### レイヤー切り替え
サイドバーの「地図レイヤー」セクションで、表示する地図を選択できます。

### 施設フィルター
サイドバーの「施設カテゴリ」セクションで、表示する施設の種類を選択できます。

### 現在地を表示
「📍 現在地を表示」ボタンをクリックすると、GPS位置情報を取得して地図上に表示します。現在地からの距離も各施設のポップアップに追加されます。

## カスタマイズ

### 施設を追加する

`data.js` の `facilities` 配列に新しい施設を追加：

```javascript
{
    id: 18,
    name: "新しい施設",
    category: "shopping",  // station, shopping, education, medical, public, park
    lat: 35.6916,
    lng: 140.0211,
    description: "施設の説明",
    icon: "🏪"
}
```

### カテゴリを追加する

1. `data.js` の `categoryConfig` に新しいカテゴリを追加
2. `index.html` のフィルターチェックボックスに追加

### スタイルをカスタマイズ

`styles.css` を編集して、色やレイアウトを変更できます。

## API キーについて

このプロジェクトは天気情報と統計情報の取得に外部APIを使用しています。

### 使用しているAPI

#### 1. OpenWeatherMap API（天気情報）
- **無料プラン**: 60回/分、1,000,000回/日まで無料
- **取得方法**: https://openweathermap.org/api
- **課金**: クレジットカードを登録しない限り課金されません

#### 2. e-Stat API（政府統計）
- **完全無料**: 課金システムなし
- **取得方法**: https://www.e-stat.go.jp/api/
- **メール登録**: 必要

### ⚠️ セキュリティ設定

APIキーはソースコードに含まれているため、**必ずセキュリティ設定を行ってください**。

詳細は **[SECURITY.md](./SECURITY.md)** を参照してください。

**すぐに行うべき設定**：
1. OpenWeatherMapのリファラー制限を設定（`https://3namo.github.io/*`のみ許可）
2. 可能であれば新しいAPIキーを再生成

これにより、第三者による悪用を防ぐことができます。

## トラブルシューティング

### 地図が表示されない
- インターネット接続を確認してください
- ブラウザのコンソールでエラーを確認してください
- ブラウザのキャッシュをクリアしてみてください

### マーカーが表示されない
- JavaScriptが有効になっているか確認してください
- `data.js` が正しく読み込まれているか確認してください
